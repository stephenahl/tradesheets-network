Pressure Washing Business Manager

Quick start guide · Google Sheets & Excel

Open it

Excel: double-click Pressure-Washing-Business-Manager.xlsx.
Google Sheets: go to drive.google.com → New → File upload → choose the file → open it → File › Save as Google Sheets. Work in the Google Sheets copy.

Set up (10 minutes)

  1. Settings: your business name and contact, hourly labor cost, tax set-aside %, mileage rate, and your service prices. Add-on prices, quote factors, frequency discounts, expense categories, payment methods and crew names are all editable here.
  2. Clients: one row per client: service, frequency and price per visit.
  3. Delete the rows marked EXAMPLE in Clients, Jobs and Expenses.

Every day

  • Jobs: log each visit. Pick the client and the price fills in. Use Price override for a one-off price and Add-on charges for extras. Set Paid? to Yes when you're paid.
  • Expenses: log supplies, fuel, insurance and other costs.
  • Clients shows each client's next due date. Overdue and due-soon clients are highlighted.

When you need it

  • Quote Calculator: enter house size, stories, extra surfaces, add-ons and frequency to get a price, estimated hours and profit.
  • Invoice: type a Job ID (for example J-0012). Print it or save it as a PDF.
  • Dashboard: type the year to see revenue, costs, profit, margin and unpaid totals by month.
Color key: yellow cells with blue text are yours to type in. White cells calculate automatically, so don't type over them.
Tip: keep client names exactly the same in Clients and Jobs. The dropdown does this for you.
