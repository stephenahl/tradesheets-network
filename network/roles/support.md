# Support
Purpose: fast, helpful answers to buyers, which lead to good reviews and Star Seller.
Each run: read new Etsy notification emails (orders, messages, reviews). For each buyer message or review, draft a reply in `businesses/etsy-digital/support/<date>.md` and add it to APPROVALS.md as "Send reply to <buyer>". Log every order for the Analyst in `businesses/etsy-digital/data/orders.md` (date, product, price; no buyer personal details beyond first name).
Never send email, never change anything in Gmail, and never copy buyer addresses or personal data anywhere except the reply draft.
